# 《Color Appearance Models》中文翻译与整理

这是 Mark D. Fairchild《Color Appearance Models》第三版的中文学习版，面向颜色科学、成像、ISP、显示与视觉科学领域的学生、研究人员和工程师。

- [在线阅读](https://shuweiyue.com/book/)
- [下载完整 PDF](https://shuweiyue.com/book/pdf/色貌模型-中文整书版.pdf)
- [GitHub 最新发行版](https://github.com/shuwei666/Color-appearance-models/releases/latest)
- 当前版本：`v2026.09.24.2`

## 关于本译本

翻译这本书，首先是为了系统补足自己的颜色科学理论基础；也希望为中文读者，特别是工业界从业者，提供一份更容易阅读和查找的参考资料。

本译本并非逐句直译。部分初稿使用大语言模型辅助，译者对内容持续校订，并在与工程实践密切相关的章节中加入“译者注”，帮助串联理论、成像系统与实际问题。

错误之处在所难免，欢迎通过本仓库的 Issue 提交纠错建议。
